# 集団タスク閲覧アプリ 仕様書

## 概要
- 目的: チーム全員の「今日やるタスク」を一画面で俯瞰し、担当・期日・状態を素早く把握する
- レイアウト: Googleカレンダー風。横にメンバー列、各列にそのメンバーのタスクカードを追加順で縦並び（時間軸なし）。メンバーが多い場合は横スクロール
- スコープ: 自分のタスクのみ編集可。他メンバーのタスクは閲覧のみ
- 対象: 同じ組織（会社チーム/家族など）にいるメンバー
- タイムゾーン: 日本固定。画面に本日の日付を表示する

## 主要機能
- メンバー列表示: メンバー名と完了件数をヘッダーに表示（他メンバー列は閲覧専用）
- タスク表示: タイトル、内容（任意）、完了チェック
- タスク追加/編集/削除: 自分のメンバー列のみ
- 完了/未完の切り替え（チェックボックス）
- 権限: 自分のメンバー列のみ追加・編集・削除が可能。他メンバー列は閲覧のみ
- 並び: 追加順のみ（手動並び替えなし）
- 認証: ログイン/ログアウト/アカウント作成
- 組織参加: 組織単位の固定参加コードで参加する
- 参加コード運用: 組織作成時に発行し、管理者のみが変更できる

## 非機能・表示要件
- レスポンシブ: PCは横スクロールで複数メンバーを並列、モバイルはメンバーを縦スタック＋左右スワイプ検討
- 視認性: 枠線は控えめ、カード背景・ホバーで区切りを示す
- 入力: フォーム枠は最小限（必要ならフォーカス時のみ表示）
- 言語: 日本語表示
- パフォーマンス: 数十人×数十タスク程度をスムーズに表示できる前提
- 文字数制限: タイトル最大80文字、内容最大500文字

## データモデル案
- Member: `{ id: string; name: string; }`
- Task: `{ id: number; memberId: string; title: string; note?: string; done: boolean; createdAt: string; }`
- Organization: `{ id: string; name: string; joinCode: string; }`
- Account: `{ id: string; email: string; name: string; organizationId: string; }`

## 操作フロー例
- タスク追加: 列末尾の「＋」からタイトル必須、内容は任意
- タスク編集: 自分の列のカードのみ編集可
- 他メンバーのタスクは閲覧のみ
- 完了チェック: カード左のチェックで即反映
- 参加: 参加コードを入力して組織に参加
